# Student Management System (C++)

## 📌 Description
A console-based Student Management System developed in C++ using file handling. It allows users to manage student records efficiently.

## 🚀 Features
- Add Student
- Display Students
- Search Student
- Update Student
- Delete Student

## 🛠️ Technologies Used
- C++
- File Handling (fstream)

## ▶️ How to Run
1. Compile:
   g++ main.cpp -o student
2. Run:
   ./student

## 📂 File Used
- students.dat
